# Master Timetable

Clean school timetable generator that runs fully in the browser.

## How to use
1. Open `index.html` in any browser
2. Click **Sample** or add your own teachers, subjects and classes
3. Click **Generate Timetable**
4. View by class or teacher, export CSV, or print

## Features
- Conflict free scheduling with load balancing
- Spreads subjects across the week
- Period time labels from start time + duration
- Duplicate code checks
- Keyboard support (Enter to save, Escape to close)
- Mobile friendly layout
- Local storage autosave
